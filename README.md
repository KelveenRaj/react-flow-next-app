# React Flow Payment Workflow

A node-based editor for sketching how a payment gets routed: set an amount, pick destination countries, then choose the payment providers for each one. Built with React Flow, using custom nodes and edges.

**Live:** https://react-flow-next-example.netlify.app/

## What's in it

- Custom nodes for payment start, country, provider and provider selection
- Custom edges and connection handles
- Country flags and currency per destination
- Light/dark mode

## Built with

Next.js 15, React 19, React Flow, Chakra UI v3

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
